Seed teachers

This page only needs to be run once. It will add 10 teacher profiles to your Firestore teachers collection, so the homepage mosaic has content. After that, keep adding / editing teachers normally from the Admin panel.

Before running this

Firestore rules usually only let a logged-in Admin write. If you see "permission denied" below, log in with an Admin account in another tab first, then refresh this page and try again.

  1. Each doc's id will be SEED-TCH-01 … SEED-TCH-10
  2. Running it again overwrites the same docs — no duplicates are created
  3. All come with status: "approved", so they'll show on the homepage right away
  4. Photos are left blank — upload them from the Admin panel; initials show until then
