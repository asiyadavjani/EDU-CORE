Seed teachers

Ye page sirf ek dafa chalana hai. Ye aapke Firestore ke teachers collection mein 10 teacher profiles daal dega, taake homepage ka mosaic bhar jaye. Uske baad aap normally Admin panel se teachers add / edit karte rahein.

Chalane se pehle

Firestore rules aam taur par sirf logged-in Admin ko likhne deti hain. Agar neeche "permission denied" aaye, to pehle doosre tab mein Admin account se login karein, phir is page ko refresh kar ke dobara try karein.

  1. Har doc ki id SEED-TCH-01 … SEED-TCH-10 hogi
  2. Dobara chalane par wohi docs overwrite honge — duplicate nahi banenge
  3. Sab status: "approved" ke saath aayenge, is liye foran homepage par dikhenge
  4. Photos khali hain — Admin panel se upload karein, tab tak initials dikhenge
