Seed students

Creates a batch of realistic test students in one click — registered, entry test taken, unique CNIC and Roll Number auto-generated — instead of filling the registration form one by one. Courses are picked from whatever you've already created in Admin → Courses, so create at least one course first.

Before running this

Firestore rules usually only let a logged-in Admin write. If you see "permission denied" below, log in with an Admin account in another tab first, then refresh this page and try again. Also make sure at least one course exists in Admin → Courses — students need a real course to register under.

  1. Each student gets a synthetic CNIC starting with 99999 — easy to spot, never colliding with a real registration
  2. Courses are split evenly across whatever real courses exist in Admin → Courses right now
  3. Entry test results are simulated realistically: most students Pass and land in "Awaiting Approval" (ready for you to Accept/Reject in Admin), a few Fail, and a few haven't taken it yet ("Entry Test Pending")
  4. Nobody is auto-Accepted — that stays your call from the Admin → Applications tab, same as with a real student
  5. Running it again adds a fresh new batch rather than overwriting the last one (each run gets its own CNIC range)
