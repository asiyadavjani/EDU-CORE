Seed demo data

This page also only needs to be run once (like seed-teachers.html, but separate / independent from it). It adds 4 demo teachers, 6 demo courses (3 campuses, each with a paid + free option), 20 demo accepted students (8 currently studying, 12 graduates — 100% progress), the last 5 days of demo attendance, 6 success stories (drawn from those same 12 graduates), 3 blog posts, and 3 news/event items — so the Admin/Teacher/Student dashboard graphs and the homepage's newer sections (Courses, Success Stories, Popular Blogs, News & Events) show up filled in instead of empty.

Before running this

Log in with an Admin account in another tab, then refresh this page and click "Add demo data". If you're not logged in, you'll get "permission denied" while writing teachers/courses/attendance.

  1. Teachers: DEMO-TCH-01 … 04  |  Courses: DEMO-CRS-01 … 06
  2. Students: fake CNICs starting 9999100000001 … 20 (won't match any real one)
  3. Success stories: DEMO-STR-01 … 06  |  Blogs: DEMO-BLG-01 … 03  |  News: DEMO-NEV-01 … 03
  4. Clicking "Add" again overwrites the same records — no duplicates are created
  5. "Remove demo data" pulls all of it back out (teachers, courses, students, attendance, success stories, blogs, news) — your real data is untouched
  6. This is all just a starter demo — you can add/edit/delete your own real content any time from the Admin dashboard's "Success Stories" / "Blog Posts" / "News & Events" tabs
